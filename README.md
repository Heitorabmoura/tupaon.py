 Tupã — Cultura e Conhecimento dos Povos Originários

 📌 Sobre o projeto

O Tupã é uma aplicação desenvolvida com o objetivo de promover o conhecimento e dar visibilidade à cultura dos povos originários. A plataforma apresenta informações sobre suas histórias, costumes, tradições, mitologias e outros aspectos culturais de forma simples e acessível.

 🎯 Objetivo

O principal objetivo do projeto é utilizar a tecnologia para facilitar o acesso a informações sobre os povos originários, contribuindo para a valorização e preservação de suas culturas.

 Sistema de avaliação ou comentários;
 Melhorias na navegação e acessibilidade.

 Correção de erros encontrados nas versões anteriores;
 Melhorias de desempenho;
 Melhorias na interface;
 Revisão dos conteúdos;
 Preparação da versão final para apresentação.

 👥 Público-alvo

O projeto é destinado principalmente a estudantes, professores e pessoas interessadas em conhecer mais sobre os povos originários e suas culturas.
